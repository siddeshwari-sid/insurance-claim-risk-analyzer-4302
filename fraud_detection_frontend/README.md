# Lightweight React Template for KAVIA

This project provides a minimal React template with a clean, modern UI and minimal dependencies.


#########⚙️ Features#########
📂 Upload CSV of claims
📊 Dashboard with risk distribution
🚨 High-risk claim detection
🔍 Search and filter claims
📋 Detailed claim view with explanations


###########🖥️ Tech Stack ################
Frontend: React + Tailwind CSS
Backend: Node.js + Express
Data: In-memory (no database)

########▶️ How to Run#########
Backend

cd fraud_detection_backend
npm install
npm start

Frontend

cd fraud_detection_frontend
npm install
npm start

############📂 Sample CSV Format#################

claim_number,claimant_name,policy_number,incident_date,report_date,amount

###########🎯 Outcome#############
Faster fraud detection
Prioritized investigation queue
Better decision making
